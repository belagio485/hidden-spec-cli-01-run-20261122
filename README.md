mend — one patch tool for every AI edit format. It reads a patch in one of four formats (unified diff, SEARCH/REPLACE blocks, V4A, JSON edits) and applies it to a tree of text files, changing every file or none.

## Run it

```sh
node main.ts [PATCH]
```

Node 22 and its standard library only; nothing is installed. See SPEC.md for the full contract: the four formats, the three matching tiers, the exit codes and the exact output.
